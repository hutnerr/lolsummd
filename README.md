## Setup
To run this locally, you need your own Riot API key and a Redis URL.

```bash
pip install -r requirements.txt
```

These are all the environment variables the app uses:

```env
RIOT_API_KEY=...
FLASK_SECRET_KEY=...
REDIS_URL=...
```
